# Czech Verb Lab

A small, self-contained interactive practice page for Czech present-tense verb conjugation.

## What it covers

- Regular verb patterns: **-at**, **-it**, and **-ovat**
- Irregular verbs: **být**, **mít**, and **jít**
- A six-person conjugation table with draggable or tap-to-place ending blocks
- Answer checking, retry, and short pattern notes

## Run locally

Open `index.html` in a modern browser. The page has no build step or backend dependency.
